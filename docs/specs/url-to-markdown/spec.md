# URL → Markdown → LLM

웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 추출해 보여 주고, 복사·다운로드하거나 프롬프트와 함께 ChatGPT·Claude로 바로 넘기는 단일 페이지 서비스.

Linked sources:
- 승인된 화면 프로토타입: [prototype.html](prototype.html) — 화면 구성, 상태(로딩·결과·긴 본문·주소 오류·가져오기 실패), 내보내기 드롭다운의 위치와 모양을 정한다. 프로토타입의 코드는 참고용이며 구현에 복사하지 않는다.
- 추출·전달 방식 결정: [docs/decisions/page-extraction-and-llm-handoff.md](../../decisions/page-extraction-and-llm-handoff.md) — defuddle 서버 실행, 서버 fetch, 긴 본문 클립보드 대체, 서버 fetch 안전 규칙을 정한다.
- UI 구성: [docs/decisions/ui-composition.md](../../decisions/ui-composition.md) — shadcn 구성, semantic token, 상태 설계, 좁은 화면 규칙을 정한다.

## 사용자 가시 결과

1. **입력** — URL 입력칸에 붙여넣고 변환을 실행한다. 지우기 버튼은 입력칸과 결과·오류를 모두 초기 상태로 되돌린다.
2. **변환** — 서버가 페이지를 가져와 defuddle로 본문을 Markdown으로 추출한다.
3. **결과 확인** — 앱 타이틀은 `Feedme`, 화면 제목은 `웹페이지를 Markdown으로`다. 페이지 제목과 저자(없으면 저자 줄 생략)를 헤더로, 그 아래 렌더링된 Markdown을 보여 준다.
4. **내보내기** — 결과 카드 바로 위 오른쪽(카드 밖)에 `복사하기` 버튼과 ▾ 드롭다운이 붙어 있다. 드롭다운에 `마크다운 다운로드`, `ChatGPT에서 열기`, `Claude에서 열기`가 있다. 결과가 있을 때만 보인다.
   - 복사하기: 프롬프트가 선택된 경우를 제외하고 Markdown 본문을 클립보드에 복사한다.
   - .md 다운로드: Markdown 본문을 파일로 저장한다. 파일명은 페이지 제목에서 만든다(제목이 없으면 도메인).
   - ChatGPT로 열기 / Claude로 열기: 선택한 프롬프트(있으면)를 본문 앞에 붙여 전달한다.
5. **프롬프트** — 프리셋 `요약해줘` / `한국어로 번역해줘` / `쉽게 설명해줘`와 `직접 입력`, 그리고 선택 안 함(기본). `직접 입력`을 고르면 텍스트 입력칸이 나타난다. 직접 입력한 문장은 저장하지 않으며 새로고침하면 사라진다.
6. **다크모드** — 토글로 라이트/다크를 전환한다.

## 승인된 범위

- 단일 페이지 UI, URL 변환 서버 처리, 결과 렌더링, 복사/다운로드/외부 채팅 열기, 프롬프트 선택, 다크모드 토글.

## 수락 기준 (관찰 가능)

1. 유효한 공개 글 URL(예: `https://stephango.com/saw`)을 변환하면 제목 "Use the saw, fear the saw"와 저자 "Steph Ango"가 헤더에 나오고 본문이 Markdown 렌더링으로 보인다.
2. 지우기 버튼을 누르면 입력칸, 결과, 오류 메시지, 직접 입력 문장이 모두 비워진다.
3. 변환 중에는 로딩 상태가 보이고 변환 버튼이 중복 실행되지 않는다.
4. 내보내기 메뉴는 ▾ 클릭으로 열리고 바깥 클릭이나 항목 선택 시 닫힌다. 복사하기 후 클립보드 내용이 화면의 Markdown 본문과 같다. 성공 피드백이 보인다.
5. .md 다운로드 파일의 내용이 Markdown 본문과 같다.
6. 프롬프트가 선택되면 ChatGPT·Claude로 보내는 텍스트가 `프롬프트 + 빈 줄 + 본문` 순서다. 선택 안 함이면 본문만 보낸다. 복사하기·다운로드에는 프롬프트가 포함되지 않는다.
7. 프롬프트+본문이 URL에 담기는 길이(8,000자 이하)이면 ChatGPT(`chatgpt.com`)·Claude(`claude.ai`) 새 채팅이 내용이 채워진 채 열린다. 초과하면 프롬프트+본문 전체가 클립보드에 복사되고 빈 새 채팅이 열리며, "붙여넣어 주세요" 안내가 보인다.
8. `직접 입력`을 고르기 전에는 텍스트 입력칸이 없고, 고르면 나타난다. 직접 입력 문장은 다른 저장소(localStorage 등)에 남지 않는다.
9. 오류가 각각 구분된 메시지로 보인다: URL 형식 오류(http·https가 아님 포함), 내부망/loopback 주소 거절, 페이지를 가져오지 못함(타임아웃·4xx/5xx), HTML이 아닌 응답, 추출된 본문이 비어 있음. 오류 상태에서도 입력은 유지되고 지우기와 재시도가 가능하다.
10. 다크모드 토글로 전체 화면(결과 렌더링 포함)이 전환되고, 첫 방문의 초기값은 시스템 설정을 따르며 선택은 다음 방문에도 유지된다.
11. 좁은 화면(모바일 폭)에서도 입력, 결과, 내보내기 동작이 모두 접근 가능하다.
12. 추출은 `defuddle` 라이브러리를 사용한다.

## 설정한 제약과 근거

- defuddle 서버 실행, 서버 fetch, 서버 fetch 안전 규칙(http·https만, 내부망 거절, 시간·크기 상한), 긴 본문 클립보드 대체: 위 결정 계약을 따른다.
- UI는 shadcn 구성과 semantic token을 사용한다(ui-composition 계약).
- 앱 UI 문구는 한국어. 글꼴은 나눔고딕(`Nanum Gothic`, 굵기 400·700·800).

## 가정 (덮어쓰기 가능)

- 프롬프트 기본값은 "선택 안 함".
- 한도 숫자는 초안이며 구현에서 조정 가능: 가져오기 타임아웃 약 10초, 응답 크기 상한 약 5MB.
- 다크모드의 시스템 기본값 + localStorage 유지.
- 변환 결과는 서버에 저장하지 않는다. 로그인·히스토리 없음.
- 변환 입력은 Enter로도 실행된다.

## 범위 밖과 이유

- 로그인·사용자 계정·변환 기록: 요청에 없다.
- LLM API 직접 호출: 외부 채팅으로 넘기는 것이 요구다.
- 자바스크립트 렌더링 페이지 전용 처리(헤드리스 브라우저): 비용이 크고 요청에 없다.
- 프롬프트 프리셋 편집·저장: 직접 입력은 1회용으로 명시되었다.

## 남은 위험

- 일부 사이트는 서버 요청을 차단하거나 본문을 JS로 그려 추출 결과가 비거나 빈약할 수 있다. 오류 메시지로 안내한다.
- `?q=` 방식은 ChatGPT·Claude의 비공식 동작이라 사이트 변경 시 채워지지 않을 수 있다(결정 계약의 재검토 조건).
- 8,000자 기준은 추정이다. 구현에서 두 사이트의 실제 한계를 확인해 조정한다.
